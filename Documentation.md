**Документация: Erly_Machine**

# Общее описание
Erly_Machine - это реализация алгоритма Эрли для синтаксического анализа контекстно-свободных грамматик. Класс позволяет задать грамматику, установить стартовый символ и проверить, принадлежит ли данное слово языку, порождаемому грамматикой.

# Методы класса

[Конструктор]
Erly_Machine()
Описание: Создает новый экземпляр машины Эрли с неинициализированной грамматикой.
Возвращает: Экземпляр Erly_Machine
Исключения: Не бросает исключений

[Set_Alphabet]
void Set_Alphabet(const std::string& str)
Описание: Устанавливает алфавит терминальных символов грамматики.
Параметры:
  str - строка, содержащая все терминальные символы грамматики
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - строка пуста
  - содержатся повторяющиеся символы

[Set_Neterminals]
void Set_Neterminals(const std::string& str)
Описание: Устанавливает множество нетерминальных символов грамматики.
Параметры:
  str - строка, содержащая все нетерминальные символы
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - содержатся повторяющиеся символы
  - символы уже присутствуют в алфавите

[Add_Link]
void Add_Link(const std::string& str)
Описание: Добавляет правило вывода в грамматику.
Параметры:
  str - строка с правилом в формате A->α, где A - нетерминал, α - строка символов
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - отсутствует -> в строке
  - левая часть правила пуста
  - левая часть содержит более одного символа
  - символ в левой части не является нетерминалом
  - встречается неизвестный символ в правой части
Примечание: пробелы и табуляция игнорируются автоматически

[Set_Start_Symbol]
void Set_Start_Symbol(char c)
Описание: Устанавливает стартовый символ грамматики.
Параметры:
  c - символ, который будет установлен как стартовый
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - символ не является нетерминалом
  - символ не был объявлен в нетерминалах

[Get_word]
void Get_word(const std::string& word)
Описание: Проверяет, принадлежит ли слово языку грамматики с использованием алгоритма Эрли.
Параметры:
  word - строка для проверки
Возвращает: Ничего (результат сохраняется во внутреннем состоянии)
Исключения:
  std::invalid_argument если:
  - в грамматике нет правил
  - не задан стартовый символ и нет нетерминалов
  - слово содержит символы не из алфавита
  - для стартового символа нет правил
  - превышено максимальное количество итераций (возможна циклическая грамматика)

[is_word_in_grammar]
bool is_word_in_grammar() const
Описание: Возвращает результат последней проверки слова.
Возвращает:
  true - если слово принадлежит грамматике
  false - если слово не принадлежит грамматике
Исключения: Не бросает исключений

# Последовательность использования
1. Создать экземпляр Erly_Machine
2. Задать алфавит (Set_Alphabet)
3. Задать нетерминалы (Set_Neterminals)
4. Добавить правила (Add_Link)
5. Установить стартовый символ (Set_Start_Symbol)
6. Проверить слово (Get_word)
7. Получить результат (is_word_in_grammar)

# Особенности реализации
- Использует алгоритм Эрли с предсказанием, сканированием и завершением
- Поддерживает ε-правила (пустые правые части)
- Автоматически выбирает первый нетерминал как стартовый, если не указан явно
- Обрабатывает грамматики с левой рекурсией
- Игнорирует пробелы и табуляцию в правилах
