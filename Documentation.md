**Документация: LR(1) Парсер**

# Общее описание
LR(1) парсер - это реализация LR(1) алгоритма синтаксического анализа для контекстно-свободных грамматик

# Основные классы

## Grammar
Класс для представления контекстно-свободной грамматики.

### Методы:
[set_start_symbol]
void set_start_symbol(char s)
Описание: Устанавливает стартовый символ грамматики.
Параметры:
  s - символ стартового нетерминала
Возвращает: Ничего
Исключения: Не бросает исключений при установке

[get_start_symbol]
char get_start_symbol() const
Описание: Возвращает установленный стартовый символ.
Возвращает: Символ стартового нетерминала
Исключения:
  std::invalid_argument если стартовый символ не был установлен

[set_terminals]
void set_terminals(const std::vector<char>& other)
Описание: Устанавливает множество терминальных символов.
Параметры:
  other - вектор терминальных символов
Возвращает: Ничего
Исключения:
  std::invalid_argument если вектор пуст

[set_neterminals]
void set_neterminals(const std::vector<char>& other)
Описание: Устанавливает множество нетерминальных символов.
Параметры:
  other - вектор нетерминальных символов
Возвращает: Ничего
Исключения:
  std::invalid_argument если вектор пуст

[add_rule]
void add_rule(char non_terminal, const std::vector<char>& production)
Описание: Добавляет правило вывода в грамматику.
Параметры:
  non_terminal - нетерминал в левой части правила
  production - правая часть правила
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - нетерминал не объявлен
  - правые части содержат неизвестные символы

[calculate_first]
void calculate_first()
Описание: Вычисляет FIRST-множества для всех нетерминалов грамматики.
Возвращает: Ничего
Исключения: Не бросает исключений

## LR_1_parser
Основной класс для LR(1) синтаксического анализа.

### Методы:
[fit]
void fit(bool logs = false)
Описание: Строит таблицу разбора на основе заданной грамматики.
Параметры:
  logs - флаг вывода отладочной информации
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - грамматика не содержит правил
  - не установлены нетерминалы
  - не установлены терминалы

[parse]
bool parse(const std::vector<char>& input_word, bool logs = false)
Описание: Проверяет принадлежность слова языку грамматики.
Параметры:
  input_word - входное слово для проверки
  logs - флаг вывода процесса разбора
Возвращает:
  true - если слово принадлежит грамматике
  false - если слово не принадлежит грамматике
Исключения:
  std::invalid_argument если:
  - fit не был вызван
  - таблица разбора не построена
  - неизвестный символ во входной строке
  - ошибка в операциях SHIFT/REDUCE
  - переполнение стека

## Wrapper
Класс-обертка для удобного взаимодействия с парсером.

### Методы:
[set_nonterminals]
void set_nonterminals(std::string str)
Описание: Устанавливает нетерминальные символы.
Параметры:
  str - строка с нетерминальными символами
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - строка пуста после удаления пробелов

[set_terminals]
void set_terminals(std::string str)
Описание: Устанавливает терминальные символы.
Параметры:
  str - строка с терминальными символами
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - строка пуста после удаления пробелов

[add_rule]
void add_rule(std::string str)
Описание: Добавляет правило в формате "A->α".
Параметры:
  str - строка с правилом вывода
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - строка не содержит "->"
  - левая часть правила пуста
  - левая часть содержит более одного символа
  - символ в левой части не является нетерминалом
  - встречается неизвестный символ в правой части

[set_start_symbol]
void set_start_symbol(char c)
Описание: Устанавливает стартовый символ грамматики.
Параметры:
  c - символ стартового нетерминала
Возвращает: Ничего
Исключения: Не бросает исключений

[fit]
void fit(bool log = false)
Описание: Подготавливает парсер к работе.
Параметры:
  log - флаг вывода отладочной информации
Возвращает: Ничего
Исключения:
  std::invalid_argument если:
  - грамматика не содержит правил
  - не установлены нетерминалы
  - не установлены терминалы
  - обнаружены конфликты в таблице разбора

[parse]
bool parse(const std::string& word)
Описание: Проверяет принадлежность слова грамматике.
Параметры:
  word - строка для проверки
Возвращает:
  true - если слово принадлежит грамматике
  false - если слово не принадлежит грамматике
Исключения:
  std::invalid_argument если:
  - fit не был вызван
  - слово содержит символы не из алфавита
  - произошла ошибка во время разбора

# Последовательность использования
1. Создать экземпляр Wrapper
2. Задать нетерминалы (set_nonterminals)
3. Задать терминалы (set_terminals)
4. Добавить правила (add_rule)
5. Установить стартовый символ (set_start_symbol)
6. Вызвать fit для построения таблицы разбора
7. Проверить слова методом parse

# Особенности реализации
- Использует каноническую коллекцию LR(1) состояний
- Поддерживает ε-правила (пустые правые части)
- Автоматически добавляет augmenting правило S' → S
- Использует символ '\x1E' как маркер конца входной строки
- Использует символ '\x1D' для представления ε-правил
- Игнорирует пробелы и табуляцию при парсинге правил
- Строит полную таблицу ACTION/GOTO для LR(1) разбора
- Проверяет корректность грамматики на этапе построения таблицы разбора
- Выбрасывает исключения при обнаружении конфликтов shift/reduce
