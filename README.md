Задание:
Даны α и слово u ∈ {a, b, c}∗. Найти длину самого длинного префикса u, являющегося также префиксом некоторого слова в L.

Решение:
- Создать класс Machine (в Machine.h) который будет состоять из следующих компонент
- Parser - принимает на вход строку, которую надо обработать и превращает её в нужный формат (в моём случае ничего не делает)
- NKA_Builder - строит по данному регулярному выражению НКА (Tree)
- PDKA_builder - строит по данному НКА наше ПДКА (DFA или DKA тут как удобнее звучит)
- MPDKA_builder - строит по данному ПДКА МПДКА
PS.. Тут стоит заметить что я всё сделал модульным, поэтому можно переписать один из классов и вставить свой

Далее, на выходе мы получаем МПДКА, описывающий язык, задающийся нашим регулярным выражением, и после этого устанавливаем поинтер в начало нашего МПДКА и буквально считываем слово, и фиксируем какой-префикс проходит по завершающему состоянию, после прохода по слову выводим максимальное значение
